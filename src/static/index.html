Reciprocal Rank Fusion (RRF) Mathematical Formula

Dense vector search captures semantic synonyms but struggles with exact product IDs or acronyms. BM25 captures exact lexical keywords but ignores semantic context. Our hybrid engine fuses both using Cormack's Reciprocal Rank Fusion:

RRF_Score(d) = ∑ [ 1 / ( k + rank_m(d) ) ]

Where k = 60. Items retrieved by both lexical and dense channels accumulate dominant scores, eliminating single-retriever blind spots.
